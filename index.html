VR Spielwiese

Eine WebXR-Basis für Experimente: Hub-Welt mit Händen, Weltenauswahl am linken Handgelenk und ein experimenteller Portal-Prototyp.

Eine Runde, ein Raum: Brille, Bildschirm und die Handys der Einsatzzentrale tragen denselben Raum-Code ein. Verbinden — und dann den eigenen Weg hinein wählen.

Spielst du im Sitzen oder im Stehen?

Sitzend wird die Sicht auf Stehhöhe angehoben, damit Tische, Karts und der Horizont da sind, wo sie hingehören.

Alle Geräte einer Runde tragen denselben Code ein. Ohne eigenen Code spielt ihr im Raum haunting.

    Zusammen spielen experimentell

    Beide Geräte tragen denselben Raum-Code ein. Die Verbindung läuft danach direkt von Browser zu Browser (WebRTC) — ohne eigenen Server.

    Für Haunting / Orbital gibt es eine eigene Startseite: #haunting.

    • Beide Handgelenke: ein Button öffnet das Menü — offen ist immer nur eins.
    • Andere Hand: Zeigen & Trigger zum Auswählen.
    • Portal-Welt: Werkzeuge hängen am Gürtel — Greifen nimmt sie, woanders loslassen lässt sie fallen.
    • Ohne Controller: drei Finger an die Handfläche = Greifen, Zeigefinger = Trigger. Ausprobieren im Eingaberaum.
    Verbindung

    Nur für den Verbindungsaufbau. Klappt eine Variante im Netz nicht, hilft oft eine andere.

    Sprache

    Aus. Antippen fragt nach dem Mikrofon; die Stimmen der anderen kommen aus der Richtung, in der sie stehen.

    Chat

    Die Brille schickt Konfig-Codes hierher (Werkzeug senden im Schießgang): Text markieren oder Kopieren am Eintrag drücken.

    Kamera

    Ganz links folgt die Kamera exakt, weiter rechts dreht sie träge nach.

    Ziehen dreht die Kamera · Mausrad ändert den Abstand

    Im Headset stehen dieselben Optionen unter Menü → Verbindung → Zuschauen. Dort wird nur die Position des anderen Spielers übernommen, die Blickrichtung bleibt deine.

    Links ziehen = gehen · rechts wischen = umsehen
